`tags.py` 的 `normalize_tags(text)`：
- 按英文逗号 `,` 拆分；
- 对每项 `strip()` 去掉首尾空白；
- 跳过空项；
- 用 `set` 记录已出现项，按首次出现顺序去重（大小写敏感，`A` 与 `a` 视为不同）；
- 返回列表。

```python
def normalize_tags(text):
    tags = []
    seen = set()
    for part in text.split(","):
        tag = part.strip()
        if not tag or tag in seen:
            continue
        seen.add(tag)
        tags.append(tag)
    return tags
```
