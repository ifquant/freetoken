# 文件索引修复

只修改 indexer.py，实现 collect_paths(root, suffixes)，供既有 CLI 使用。

- 递归收集 root 下普通文件；结果为相对 root 的 POSIX 路径，字典序排序。
- 排除所有隐藏文件/隐藏目录（任一路径段以点开头），排除所有符号链接，不跟随链接目录。
- suffixes 可为 py 或 .py 这样的扩展名，规范为带点后按大小写敏感匹配；重复筛选项不重复输出。
- 空 suffixes 表示保留所有符合前述条件的文件。空目录返回空列表。
- 保持 CLI，使用标准库，不提交、不修改其他文件，不覆盖既有用户修改。
- 运行 `python3 -B checks.py`，最后报告真实结果。
